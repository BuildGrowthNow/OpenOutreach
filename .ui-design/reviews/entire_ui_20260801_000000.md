## Fixed: Critical

### Split auth store — sidebar used stale `auth-store`, header/layout used `authStoreV2`

**File:** `frontend/src/components/layout/sidebar.tsx:9`  
**Problem:** Two separate Zustand store instances. Sidebar logout cleared localStorage but never cleared `authStoreV2.accessToken`, leaving API clients authenticated after logout.  
**Fix:** Changed sidebar import to `@/lib/authStoreV2`. `ProtectedRoute` watches `isAuthenticated` on the v2 store and redirects on logout.
